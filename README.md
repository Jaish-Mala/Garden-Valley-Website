# Garden Valley Restaurant Website 🍽️

A modern, responsive restaurant website designed for **Garden Valley Restaurant, Badlapur West**.

The website provides customers with an easy way to explore the restaurant, view the menu, check reviews, find the location, and get in touch for orders or enquiries.

## 🌐 Live Website

[Visit Garden Valley Restaurant Website](https://garden-valley-restau-b7ws.bolt.host)

## ✨ Features

- 🏠 Modern restaurant homepage
- 🍽️ Menu section
- 📱 Fully responsive design
- 💬 WhatsApp contact option
- ⭐ Google reviews section
- 📍 Restaurant location
- 📞 Contact information
- 🚚 Dine-in, takeaway and delivery information
- 🎨 Clean and modern UI
- ⚡ Fast and user-friendly experience

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## 📱 Responsive Design

The website is designed to work smoothly across:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📱 Tablet

## 🎯 Project Purpose

This project was created as a modern website solution for a local restaurant to improve its online presence and make important restaurant information easily accessible to customers.
